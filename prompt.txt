# MASTER DEVELOPMENT PROMPT – UNIVERSAL EDA LIBRARY CONVERTER FOR SIEMENS Xpedition 2510

## 1. Your Role

Act as a Senior EDA Software Architect, PCB Library Engineer, Reverse Engineering Specialist, and Full-Stack Software Developer.

Your task is to research, design, and develop a professional engineering application capable of converting electronic component libraries from multiple EDA software platforms into a format compatible with **Siemens Xpedition Enterprise 2510**, which is used in my organisation.

This is intended for actual PCB engineering workflows, not a demonstration or basic file converter.

## 2. Main Objective

Develop a Universal EDA Library Converter that accepts component libraries from different PCB design software platforms and converts their engineering data into Siemens Xpedition 2510-compatible library objects.

The application must support:

- Schematic symbols (CAE).
- PCB cells / footprints / decals.
- Component definitions.
- Pin information and pin-to-pad mapping.
- Padstacks.
- Component attributes and metadata.
- 3D component models.
- Mechanical and graphical information.

Preserve the original engineering properties as accurately as possible.

## 10. Important Development Rules

1. Research before implementation.
2. Do not assume file compatibility based only on extensions.
3. Do not create fake Xpedition files.
4. Do not claim complete conversion if properties are missing.
5. Never silently change pin numbering or electrical information.
6. Preserve original input files.
7. Maintain source traceability.
8. Keep all conversion engines independent.
9. Build automated test cases using sample libraries.
10. Validate generated objects in the actual Xpedition 2510 installation.
11. Clearly distinguish verified functionality from experimental functionality.
12. Do not use proprietary organisational libraries as public training or testing data.
